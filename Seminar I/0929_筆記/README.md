# 題目:微型氣體感測器產品設計開發

**演講日期**：2026/09/29  
**講者**：蕭育仁

---

## 一、技術核心：MEMS 晶片設計與製程

### 1. 感測器三大核心指標
靈敏度（Sensitivity）：微量氣體濃度變化所引起的電壓／電阻訊號變化量。

選擇性（Selectivity）：分辨不同氣體的能力（傳統薄膜選擇性有限，現行主流結合感測陣列與演算法進行特徵判別）。

再現性與響應速度（Repeatability & Response Time）：長期/重複作動的穩定度，以及反應時間（爭取預警關鍵秒數）。

### 2. 懸空微加熱器（Micro-heater）結構
作用機制：金屬氧化物感測薄膜需在 300～400°C 高溫下運作。

懸空與熱隔離設計：

晶片背面採用高深寬比蝕刻（類似 TSV 矽穿孔）將底部掏空。

將熱量高度侷限在感測核心區域，大幅降低熱傳導損耗。

功耗控制：功耗可壓低至 3.9 mW，結構熱形變極小（約 0.5 pm）。

電極材料：經熱電模擬，白金（Pt） 相較黃金具備更佳的低阻抗、耐高溫抗氧化性及化學穩定度。

### 3. 感測薄膜與材料工程
半導體材料選用:

N型(主流，佔90%):以氧化鋅(ZnO)、二氧化錫(SnO2)為主。導電依靠氧空缺缺陷產生的傳導電子，載子傳導速度遠快於P型的電洞。

P型:用於特殊氣體選擇性或建構PN接面。

共濺鍍與貴金屬摻雜（專利技術）：

採金屬靶與陶瓷靶雙靶電漿共濺鍍，精準調控成分。

摻雜銀(Ag)產生表面催化作用，並增加ZnO晶格氧空缺，提升對硫化氫(H2S)等特定毒氣的靈敏度。

### 4. 量產規模與封裝製程
晶圓規格：單片 6 吋晶圓可切割出超過 20,000 顆 Die（成熟晶片尺寸小於 800 × 800 µm）。

切割與封裝：採用 Disco 雷射隱形切割（Stealth Dicing） 避免碎屑污染懸空薄膜結構；封裝使用 TO-CAN 金屬基座 或 陶瓷載體。

代工夥伴：由亞太優勢（APM）等具備成熟無應力膜層技術的專業 MEMS 代工廠承製。

## 二、演算法、場域驗證與系統整合

### 1. 後端訊號處理與演算法補償
溫濕度動態補償：環境溫濕度漂移是化學感測器的主要雜訊來源，需搭配專屬演算法校正補償，防止數值虛報。

陣列特徵辨識：利用多通道不同塗層感測器組合成陣列，藉由特徵圖譜辨識混合氣體。

### 2. 實地驗證案例
半導體廠務區（環宣科技竹南廠）：

在研磨廠務排氣口配置四通道模組進行長達一年實測。

成功即時捕捉燒結爐逸散之 VOC 峰值。

背景雜訊與訊號靈敏度表現優於市售標竿產品（如 SGX Sensortech、NTP）。

### 3. 反應時間優勢
傳統防爆感測器需較大氣體擴散空間，響應時間多在 16 秒以上。

微型晶片可在 8～13 秒 內快速反應，在工業氣爆（如乙烯、丙烯）或粉塵閃燃時爭取關鍵黃金應變秒數。

## 三、商業化策略與市場定位

| 評估面向 | 傳統工業感測器 | 新創微型 MEMS 感測器 |
| :--- | :--- | :--- |
| **產品定位** | 固定式、防爆大機台（不易取代） | 可攜式、穿戴式、移動巡檢 |
| **成本／售價** | 30,000～60,000 NTD | 晶片微型化量產，具成本優勢 |
| **市場目標** | 既有工業安規市場 | 初期切入全球化學感測器市場約 3% |
| **目標應用** | 固定廠房死角監控 | 移動巡檢車、冷鏈水果 |

---

產品變現與落地關鍵：由「賣晶片」轉向「模組與系統」

1.降階導入門檻：一般終端客戶缺乏類比/感測前端電路與微弱訊號放大能力，若僅販售單晶片導入週期極長。

2.整合 Remark MCU 模組：

將晶片、微加熱驅動、訊號讀取電路與微控制器（MCU）封裝為整合模組，直接輸出標準數位通訊訊號（如 UART/I2C）。

國外/對岸同級陣列模組單價可達 25 萬 NTD，自主模組能以更具競爭力（如半價）的成本切入市場。

3.專利佈局與智財防護：

針對特殊共濺鍍粗糙表面結構、懸空支撐層與加熱電極幾何圖案申請發明專利，建立專利壁壘。
